## 5. Architectural Originality & Core Decisions

CelebrAI was built around four deliberate software engineering principles:

1. **Deterministic Financial Math:** LLMs are strictly excluded from performing financial arithmetic. Category allocations, actual expenditures, remaining balances, and contingency reserves are computed deterministically via `recomputeBudget()` in `src/lib/store.ts`.
2. **Transparent Event Readiness Scoring:** An explainable 4-dimensional model (Budget 25%, Timeline 25%, Vendors 25%, Tasks 25%) implemented in `src/lib/readiness.ts` provides users with transparent scoring and actionable recommendations.
3. **Non-Destructive Plan Merging:** In `src/lib/store.ts:applyPlanNonDestructive`, AI plan updates reconcile against existing event state using normalized set comparisons, ensuring custom user edits and completed tasks are never overwritten or duplicated.
4. **Resilient AI Fallback Architecture:** `src/lib/ai-provider.ts` pairs Google GenAI inference with a token-bucket rate limiter, multi-model failover (`gemini-3.8-flash` $\to$ `gemini-3.5-flash`), prompt sanitization, and an offline domain fallback engine with prominent user disclosure banners.
